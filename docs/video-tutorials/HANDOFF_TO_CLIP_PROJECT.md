# ส่งต่อให้ project ทำคลิป — วิดีโอสอนใช้ Conjoint และ Brand Health Check

วางไฟล์นี้ (หรือข้อความทั้งหมดนี้) ให้ Claude ของ project ทำคลิป

## โจทย์
ทำวิดีโอสอนใช้งาน 2 ตัว สำหรับคนทำวิจัยตลาดจริง (ไม่มีส่วน thesis/academic) ของแพลตฟอร์ม
SWU Marketing Research (swumkt.org) · ภาษาไทย · เสียงพากย์จาก **ElevenLabs** (ใช้ pipeline/ค่าตั้งเสียงที่ project นี้ทำไว้แล้ว)

## วัตถุดิบ (repo meekinhua/swumkt · branch claude/vigilant-brown-g695x1 · โฟลเดอร์ docs/video-tutorials/)
- `scenes.json` — 28 ฉาก (Conjoint 14, Brand Health Check 14) แต่ละฉากมี
  `id`, `video`, `title_th`, `visual_th`, `narration_th` (บทพากย์), `duration_hint_s`, `callouts` (จุดที่ต้องเน้น), `media.video` / `media.still`
- `storyboard.md` — ตารางเดียวกันแบบอ่านง่าย + หมายเหตุคนตัดต่อ
- `record.js` — อัดภาพหน้าจอต่อฉาก (Playwright) จากระบบจำลองของ swumkt → `out/<id>.webm` + `out/<id>.png`
  วิธีรันอยู่ใน `README.md` (ต้องรัน `backend/scripts/dev_sim.py` ของ swumkt ก่อน)

## สิ่งที่ขอให้ project นี้คิด/ทำ
1. เลือกเสียง ElevenLabs ภาษาไทยที่เหมาะกับวิดีโอสอน (สุภาพ ไม่เร็ว) และตั้งค่าที่เคยได้ผลดี
2. ปรับบทพากย์ใน `narration_th` ให้พูดลื่นขึ้นได้ แต่**ห้ามเปลี่ยนความหมาย** โดยเฉพาะฉาก C5 (ห้ามแก้ชุดคำถามหลังเริ่มเก็บข้อมูล) และ C11 (ดูคุณภาพข้อมูลก่อนเชื่อผล) ซึ่งเป็นบทเรียนจากข้อมูลจริง
3. ความยาวฉากให้ตามเสียงจริง: ภาพยาวไม่พอให้ค้างภาพนิ่ง (`media.still`) หรือชะลอวิดีโอ
4. ใส่ซับไทย, กรอบ/ลูกศรตาม `callouts`, title card ต้นและท้าย
5. ส่งออก 1080p 16:9 (เว็บ) — ถ้าระบบทำได้ง่าย ทำ 9:16 เพิ่มสำหรับมือถือ

## ข้อห้าม
- ใช้ภาพจากระบบจำลอง (ข้อมูลสังเคราะห์) เท่านั้น ห้ามใช้ข้อมูลจริงของนิสิตจาก swumkt.org
- ซ่อน/ครอปป้าย "ADMIN" และชื่อบัญชีมุมขวาบน (สคริปต์อัดตอนนี้ login เป็น admin ของระบบจำลอง)
- ไม่พากย์ตัวเลขเฉพาะจากข้อมูลจำลอง ให้พากย์ "วิธีอ่าน"
- อย่า commit API key ของ ElevenLabs ลง repo
