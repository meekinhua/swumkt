# วิดีโอสอนใช้งาน — Conjoint & Brand Health Check (สำหรับงานวิจัยจริง)

สถานะ: **เตรียมไว้ ยังไม่ได้ถ่ายทำ** · ไม่รวมส่วน academic / thesis export

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `storyboard.md` | บทพูดภาษาไทย + ภาพที่ต้องเห็น ทีละฉาก (2 วิดีโอ) |
| `scenes.json` | ฉากเดียวกันในรูปข้อมูล — ป้อนให้ระบบทำคลิป (เสียงพากย์, ซับ, ตัดต่อ) |
| `record.js` | สคริปต์ Playwright อัดหน้าจอทีละฉากจากระบบจำลอง (`backend/scripts/dev_sim.py`) |

## ขั้นตอนเมื่อพร้อมทำคลิป
1. รันระบบจำลอง (ข้อมูลสังเคราะห์ ไม่แตะข้อมูลจริงของนิสิต):
   `python backend/scripts/dev_sim.py --port 18099 --frontend-dir <build ที่ชี้ REACT_APP_BACKEND_URL=http://localhost:18099>`
2. อัดภาพ: `node docs/video-tutorials/record.js` → ได้ไฟล์ `out/<scene-id>.webm` + `out/<scene-id>.png` ต่อฉาก
3. ส่ง `scenes.json` + โฟลเดอร์ `out/` เข้าระบบทำคลิป: ใช้ `narration_th` ทำเสียงพากย์/ซับ,
   ใช้ `video` เป็นภาพ, `duration_hint_s` เป็นความยาวโดยประมาณ, `callouts` เป็นกรอบ/ลูกศรเน้นจุด
4. ภาพที่อัดใช้ข้อมูลจำลอง: ข้อความบนจอมีคำว่า "ข้อมูลจำลอง" — คงไว้ ห้ามใช้ข้อมูลจริงของนิสิตในคลิปสาธารณะ

## ยังต้องตัดสินใจ
- ระบบทำคลิปตัวไหน (repo / เครื่องมือ) และรูปแบบ input ที่มันรับ — `scenes.json` ออกแบบให้แปลงง่าย
- เสียงพากย์: คนจริง หรือ TTS · ความละเอียด 1080p แนวนอน (เว็บ) และ/หรือ 9:16 (มือถือ/Reels)
- ฉากที่ต้องใช้ AI (ตีความผล) ถ่ายด้วยทาง "ใช้ AI ของฉันเอง" เพราะ AI ของระบบปิดอยู่บน production
