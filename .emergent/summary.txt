**Key Technical Concepts**
-   **Database Indexing:** Creating indexes on MongoDB collections (, , etc.) via a startup event in FastAPI to ensure high-performance queries, especially in production environments.
-   **Batch Processing for Long-Running Tasks:** Modifying a backend endpoint to process a large task in smaller, manageable chunks to avoid server/database timeouts. The frontend then polls this endpoint until completion.
-   **Incremental Loading (Infinite Scroll):** Using  to detect when a user scrolls to the bottom of a list and trigger an API call to fetch the next batch of data, improving initial page load time and user experience.
-   **Global API Error Handling (Axios Interceptors):** Centralizing API request logic to add universal features like request timeouts and response error handling (e.g., automatically logging out on a 401 status code).
-   **Image Lightbox:** A UI pattern where clicking a thumbnail opens a full-screen modal overlay to display a larger version of the image, often with navigation controls to cycle through a gallery.
-   **Responsive Web Design with TailwindCSS:** Using utility classes with breakpoints (e.g., , ) to create layouts that adapt to different screen sizes.
